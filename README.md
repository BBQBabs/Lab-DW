# Catálogo de películas de terror

Aplicación web hecha con React y Vite. Permite buscar películas, filtrarlas por género, año y calificación, ver el detalle, guardar favoritas y calificar de 1 a 5 estrellas.

## Cómo ejecutarlo

1. Instalar [Node.js](https://nodejs.org).
2. Clonar el repositorio y entrar a la carpeta:
   ```
   git clone URL_DEL_REPOSITORIO
   cd catalogo-terror
   ```
3. Instalar y ejecutar:
   ```
   npm install
   npm run dev
   ```
4. Abrir http://localhost:5173
